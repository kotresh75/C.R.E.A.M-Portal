# ⚙️ AGENTS.md – Project Standards & Rules

## 1. Documentation Management (MANDATORY)

* All project documentation MUST be read from and written to the **Obsidian MCP server**.
* Documentation MUST ONLY be stored within the **"CREAM Portal"** folder in the Obsidian vault.
* DO NOT store project documentation locally in the workspace (e.g., bypassing the MCP server).
