# Phase 6: Project Planning & Work Plan

## 1. Role Assignment
To ensure efficient execution of the C.R.E.A.M Portal project within the 15-week timeframe, roles have been distributed based on team members' core strengths:

- **Kotresh C:** Team Lead, Full Stack Integration, Project Management.
- **Chinmay Homkar:** Frontend Development, UI/UX Design (React, UI frameworks).
- **Preetham Javali:** Backend API Development, Database Management (FastAPI, MongoDB).
- **All Members:** Research, Documentation, Field Survey, and Final Presentation.
